Program data comes from your providers: Xtream panels serve it themselves, M3U providers need an EPG URL. A channel shows a guide when its tvg-id matches a channel id in a source. When several guides have it, the one with the lowest priority number wins. A provider's guide uses the provider's priority unless you give it its own here, so you can rank guides without changing the failover order.
